# 更新记录

## 0.2.0 · 2026-10-22

- 2.5D 战机改用 Quaternius 的 10 种独立舰体与 12 款配色，战场引入 KayKit 殖民基地、着陆平台和跑道；两套社区资产保留 CC0 许可与作者来源。
- 新增独立的 3D 星际空战模式、电脑飞行与多指触屏操作、机炮、护盾、推进、重生、追尾/驾驶舱镜头及房间战绩。
- 新增荒漠、冰海、火山与深空四个 20 公里战区，包含保存的地形、地标、基地、空间站、小行星与 1990 个服务端静态碰撞代理；支持三秒充能跃迁。
- 使用三通道 ENet 与服务端权威战斗，房主模式 1+31、专服 32 客户端；两种真实独立进程容量测试均通过满房、溢出拒绝、跨四区战斗与断线重连。
- 协议 v2 使用 tick 阻止跨通道旧名单覆盖新战区状态，并校验状态范围；弹道按地形三角形与静态障碍做遮挡，防止穿山命中。
- 新增 8 个静态空战音频资源，并修复长截图帧后循环音频退出时释放过早的问题。
- 新增 82 项战斗/协议、31 项 3D 资产、24 项 3D 界面流程检查；保留 2.5D 检查。发行包与 Android 验证见对应文档。
- GPU 压力检查改为每帧主动绘制并交换缓冲，记录完成帧数、像素哈希与四战区截图，避免窗口被遮挡后以继续模拟误判渲染通过；支持独立的 .NET 运行时与渲染线程对照。原生崩溃仍未解决，安装包保留为候选版本。

## 工作区资产化重构 · 2026-10-22

- 主场景直接引用战场、UI 和音频场景，静态飞机、灯光、相机和菜单可在编辑器中预览。
- 十二款战机、五种危险物/补给/特效预制、共享网格与材质固化为独立资产；机体名称、价格和外观引用改为 `.tres` 数据。
- 七个 UI 页面与主题独立保存，页面切换复用节点；音乐和六种音效改为 WAV 资源与静态播放节点。
- 运行时代码保留状态推进、输入、实例化、动画与数据绑定，移除逐个构建网格、界面和音频采样的启动逻辑。
- 新增 39 项资产检查，并通过 20 项核心检查与 24 项界面/输入流程检查。资产使用方式见 [资产工作流](assets.md)。

## 0.1.1 · 2026-10-14

- 修复安卓相对拖动在战场投影边界之外变成零位移的问题；现在手指可在屏幕可用区域内持续拖动，飞机仍受战场边界约束。
- 越界后反向拖动立即响应，细小滑动不再被原来的移动死区吞掉。
- 松手或系统取消触控时立即清空未完成的移动目标，避免残留漂移。
- 新增横向/纵向越界、反向、飞机边界、细微滑动、触控取消与双指技能回归。在 1280×720 与 1920×864 两种窗口尺寸下，各 23 项流程检查通过；20 项战斗与存档检查通过。
- 安卓包版本号更新为 0.1.1（versionCode 2），保留应用 ID 和调试签名，支持覆盖安装保存本地进度。真机触感仍由设备复验。
