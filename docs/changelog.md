# 更新记录

## 0.1.1 · 2026-10-14

- 修复安卓相对拖动在战场投影边界之外变成零位移的问题；现在手指可在屏幕可用区域内持续拖动，飞机仍受战场边界约束。
- 越界后反向拖动立即响应，细小滑动不再被原来的移动死区吞掉。
- 松手或系统取消触控时立即清空未完成的移动目标，避免残留漂移。
- 新增横向/纵向越界、反向、飞机边界、细微滑动、触控取消与双指技能回归。在 1280×720 与 1920×864 两种窗口尺寸下，各 23 项流程检查通过；20 项战斗与存档检查通过。
- 安卓包版本号更新为 0.1.1（versionCode 2），保留应用 ID 和调试签名，支持覆盖安装保存本地进度。真机触感仍由设备复验。
