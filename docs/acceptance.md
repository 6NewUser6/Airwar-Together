剩余验收：

- Android 的真实触屏点击/拖动与实际像素画面。模拟器的 Android 系统服务反复崩溃，已有桌面、黑屏和系统错误弹窗截图均未当成游戏画面通过。用户确认暂时没有可连接的安卓手机，同意保留真机验收；不以 APK 导出和输入 API 注入代替。
- 较长时间交互运行和 32 架同屏切区压力均出现 Godot 原生崩溃。续查已发现遮挡窗口会使旧压力工具停止实际绘图，现增加逐帧主动绘制、实际完成帧数、像素哈希与四区截图；补强后的 .NET 8 对照约 80 秒再次访问异常。现有安装包仍属于待稳定性修复的候选版本；对照结果见 [原生渲染排查](native-render-investigation.md)。
- 公网弱网与不同物理设备的 Wi-Fi 表现尚未验收。网络容量证据来自真实 ENet 连接，但运行在同一宿主机/模拟器网络。

Windows 包、APK、网络原始报告与截图在本机忽略目录 `builds/` 和 `artifacts/`。源码和本轮改动尚未提交或推送。
