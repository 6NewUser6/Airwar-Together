# Airwar Together

基于 Godot 的飞机大战项目，目前处于工程初始化阶段。

## 打开工程

使用 Godot **4.7.2 .NET** 导入 `airwar-together/project.godot`。C# 工程需要 .NET 8 或更新的 SDK。

```powershell
dotnet build .\airwar-together\airwar-together.csproj
```

游戏场景和玩法尚未实现，后续将在这个工程中开发。
