# 三维战区资产

四个战区场景位于 `scenes/arena/sectors/`。每个战区宽 20 km，使用米作为单位。地形、基地、航道环、小行星及空间站均为存储在工程中的静态资产；游戏只实例化玩家、弹道和切换所需的战区。

`tools/bake_arena_world.py` 是离线资产制作工具。它生成可编辑的 OBJ、材质、场景和服务端碰撞数据。运行它会重写这些生成文件，手工改动需同步回工具或另建继承场景。它属于游戏资产管线，不依赖参考工程或 MCP。

地表由 16 个区块组成，合计 160 × 160 网格，顶点间距 125 m。所有顶点高度来自 `scripts/Arena/ArenaTypes.cs` 的 `SectorCatalog.GroundHeight` 公式。物理高度应在同一网格的两个三角形上插值；冰海水面高度为零。修改公式后须重新烘焙地形，同时更新服务端高度算法。

`collision_world.json` 是实际地标的服务端碰撞代理。根数组中 `box.size` 表示三个轴上的**半长**，`sphere.radius` 表示半径；坐标全部为所在战区中的世界坐标。建筑采用多个轴对齐盒，圆环使用沿圆周分布的球，中央通道保持开放。它们是性能友好的近似碰撞体。地表高度另行计算，熔岩面不作为固体地表。

`props/MiningOutpost.tscn` 引用 KayKit Space Base Bits 的 8 种模型，许可证与原始文件位于 `assets/community/kaykit_space_base/`。其余地形、航道环、空间站、小行星、行星材质和天空着色器是本项目制作的资源。
